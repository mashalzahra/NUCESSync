# 📚 Academic Productivity Hub

A responsive academic productivity web app built with **HTML, CSS, and vanilla JavaScript**, designed to bring everyday student tools into one place.

### ✨ Features

- 📅 Timetable visualization & exam countdowns
- ✅ CRUD-based to-do list & deadline tracking
- 📝 Subject-wise notes management
- 🍅 Pomodoro timer with session tracking
- 📊 Progress indicators & CGPA calculator
- 🌙 Dark mode & dynamic reminders
- 📱 Responsive layout

### 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript

Built to organize student life. Results may vary. :)
